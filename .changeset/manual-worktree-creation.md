Create a Git worktree from the Workspaces **+** without starting an agent, or ask an agent in a new conversation without leaving your current one. In the manual form, enter a worktree name to get a suggested branch and a location under the project's default worktree folder. From the confirmation, open the new worktree or conversation, or close it to stay where you are. Set a default folder for the machine and override it in Project settings.
