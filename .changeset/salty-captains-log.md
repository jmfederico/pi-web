Add Captain's Log, an optional prebuilt Pi package that retells the selected conversation's last completed assistant reply as a theatrical pirate briefing without modifying the original. Use “Let the Captain tell it” for nautical metaphors and humor, with instructions to preserve important facts and keep code and commands exact. Install it from Available packages and explicitly enable its plugin; no compilation is required. Replies render as Markdown with formatted lists, links, and code blocks, without executing embedded HTML or loading remote images. Its themed, one-button panel reuses the pirate conversation while available and creates one automatically otherwise, preserving old sessions and results. The browser, backend, and native companion communicate through public messaging APIs with pushed progress, no polling, and no automatic resend after disconnects.
