Ship Files as an enabled-by-default, disableable bundled browser plugin backed by backward-compatible browser API v2 additions for host-routed preview/download URLs, cancellable uploads, bounded contribution navigation, and scoped file invalidation. Existing workspace-file adapters and test fakes remain source compatible, and disabling the Files UI leaves host workspace-file access available to attachments and other plugins.
