Add browser-plugin content previews shared by chat Markdown, Files Markdown previews, and standalone text files, with bundled Mermaid diagrams. Renderers, including Mermaid, default to manual: raw source stays visible until Render is clicked. Plugin authors can explicitly opt into automatic rendering. Chat provides compact per-diagram Render, Raw, and Copy source controls; standalone files use the Files header’s Render/Raw controls beside Download. Files’ saved Raw/Preview preference overrides rendering defaults, including manual Markdown fences, while URL mode retains precedence and Markdown blocks retain their Raw controls and renderer choices. Fresh browsers use the plugin default without saving it as a choice; unrelated prose updates preserve rendered diagrams. Tall rendered previews remain scrollable in Files without clipping their bottom, while the Files header stays pinned; chat and Files retain keyboard access to diagrams. Built-in Files previews are unchanged. When multiple renderers match, choose an alternative per diagram or file; defaults follow alphabetical plugin ID and contribution ID order, and only the selected preview runs. Chat remembers explicit per-block renderer and Raw/Preview choices in this tab for 15 minutes from the last explicit choice, without extending expiry on viewing or unmounting active previews at expiry. Changed source or unavailable renderers invalidate remembered choices; Files Markdown previews do not use this memory. The public content-rendering capability keeps Chat memory private, accepts a dedicated Markdown request and an explicit `allowManualPreview` override, and reserves renderer IDs for externally controlled text previews so embedded choosers remain independent. Renderer callbacks receive only text, cancellation, and failure reporting. Chat retains raw source and copying during streaming and preview failures; diagram rendering runs locally in a network-blocked sandbox.
