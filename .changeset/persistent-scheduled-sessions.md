Add first-class workspace automations on local and federated machines with manual, one-shot, interval, and timezone-aware cron triggers. Each target machine stores and executes its own schedules in fresh daemon-owned Pi sessions with fixed model and thinking settings, configurable timeouts, durable cancellation, immutable run history, and visual duration, token, and estimated-cost reporting. Automations can be disabled per machine so the daemon does not load their database or scheduler.
