Work from any device

Remote access

Use your laptop, phone, or tablet to direct agents and review their work. Projects, tools, and sessions stay on a host you control. Keep that host running and connect through a trusted private path.

Keep work on one host

Run PI WEB on a workstation, dev box, home server, or cloud VM. Repositories, dependencies, caches, and credentials stay there, so changing devices does not mean moving your development environment. A laptop works too, but its agents cannot keep working while it sleeps or shuts down.

Return to running sessions

Close a browser tab or lose your connection without stopping agents on the host. Sessions run separately from the browser and web/API service; reconnect to return to their work.

Keep the host and session daemon running. A host shutdown or session-daemon restart can interrupt active work. Browser reconnects and web/API restarts do not protect against those interruptions.

Run work in parallel

Use separate sessions and worktrees for independent tasks on the same host. If your work spans several hosts, connect trusted machines and switch between them from one PI WEB URL.

Switch devices, not environments

Open the same PI WEB address from another device to reach your projects and sessions. The browser gives you access to conversations, files, diffs, and terminals without installing PI WEB on every device.

Direct agents and review changes

Set a task and its constraints, inspect transcripts, and send follow-up instructions. Review changes before deciding what ships; remote access keeps those decisions available wherever you connect.

Connect privately

Choose an SSH tunnel, VPN, private LAN, or authenticated reverse proxy. The remote access setup guide includes the SSH command and network precautions; see reverse proxy setup for root and path-prefix deployments.

Do not expose PI WEB directly to the public internet. It can run commands and access files with the server user's permissions. Use a trusted private connection or an authenticated reverse proxy.
