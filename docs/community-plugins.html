    Install a plugin
    1. Copy the package name from npm.
    2. In PI WEB, open Settings → Pi packages on the machine where you want to install it.
    3. Enter npm:package-name (or npm:@scope/package-name) and choose Install.
    4. Open Settings → PI WEB plugins to check the integration and enable it if needed. Follow any reload or restart guidance shown there.

    Installing a package and enabling its web integration are separate decisions. See Install and manage for details.

    Share your plugin

    Publish a public npm package with a working piWeb.plugins declaration and add these keywords to its package.json:

    {
  "keywords": ["pi-web.dev-plugin", "pi-package"]
}

    The directory searches only for pi-web.dev-plugin. Add this keyword even if your package already uses the broader pi-web-plugin tag.

    No keyword registration or submission to PI WEB is needed. Publish a new package version with the keywords; discovery depends on npm search indexing and may not be immediate.

    Include a useful description, repository link, installation instructions, and supported PI WEB versions so users can evaluate your package. The keyword makes it discoverable; it does not replace the plugin manifest.
